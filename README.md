SkillBridge is a web application designed to connect individuals in local communities who want to exchange skills or services without relying on money. The platform allows users to offer what they know — such as tailoring, tutoring, farming, or tech skills — and request what they need in return. 

Each user can create a profile showcasing the skills they offer and the ones they wish to learn. The system then matches users with complementary needs, enabling direct collaboration and skill exchange. 

The goal is to reduce poverty and unemployment by encouraging people to use their talents productively, learn from each other, and strengthen community connections. 

This project aligns with SDG 1 (No Poverty), SDG 8 (Decent Work and Economic Growth), and SDG 10 (Reduced Inequalities).
